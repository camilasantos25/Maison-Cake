# Maison Cake 🍰
Landing page fictícia de uma confeitaria artesanal, desenvolvida como prática de React e Tailwind CSS, com foco em aprender componentização, gerenciamento de estado, formulários controlados e dark mode.

Este projeto não representa uma empresa real, foi criado apenas com o intuito de estudar e praticar desenvolvimento front-end.

Link do projeto: [https://maison-cake-nine.vercel.app/]

### Funcionalidades
- Layout completo inspirado em uma landing page de confeitaria, com header, hero, cardápio, sobre nós, depoimentos e footer
- Modal de encomenda com formulário controlado e validação de campos obrigatórios
- Dark mode com alternância manual entre tema claro e escuro
- Layout responsivo, com menu hambúrguer para mobile

### Tecnologias
- React
- Tailwind CSS
- JavaScript
- Vite
